# Chrome Web Store listing

## Name

ContestRadar — coding contest radar

## Short description

The next five contests from Codeforces, LeetCode, CodeChef, AtCoder, and HackerRank.

## Long description

ContestRadar puts the next five coding contests in your browser toolbar.

- One normalized schedule across five platforms.
- Local time and IST labels.
- Platform color coding and duration.
- One click to the full ContestRadar schedule.
- No account required for the popup.
- No ads, no tracking scripts, no sponsored rankings.

Data refreshes from the public ContestRadar API.

## Category

Developer Tools

## Permissions justification

- `storage`: reserved for the local refresh timestamp. No personal data is stored.
- `host_permissions` for `https://contestradar.vercel.app/*`: required to fetch the public
  contest schedule.

## Privacy

The extension sends no personal data. It does not read browsing history, tabs, cookies,
or page content. Requests go only to the ContestRadar API.

Privacy policy: https://contestradar.vercel.app/privacy
